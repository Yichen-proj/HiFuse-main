# Data

Large dataset files are not stored in this source repository. HiFuse was evaluated on 14 publicly available spatial multi-omics datasets, including four from the 10x Genomics Visium platform, three from the SPOTS platform, four from the MISAR-seq platform, two from the spatial epigenome-transcriptome co-profiling platform, and one simulated dataset. All public datasets used by HiFuse can be downloaded free of charge from Zenodo: [Spatial multi-omics datasets for HiFuse](https://doi.org/10.5281/zenodo.22986116).
